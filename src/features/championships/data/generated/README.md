# Generated championship data

Do not edit these files by hand. They are regenerated by scripts and any manual
change is lost on the next run.

| File                                | Script                         | Committed |
| ----------------------------------- | ------------------------------ | --------- |
| `championships.snapshot.json`       | `npm run championships:sync`   | Yes       |
| `championship-assets.manifest.json` | `npm run championships:assets` | Yes       |

Both outputs are deterministic: running a script twice without changing anything
leaves the files untouched. The snapshot is a first-render and offline fallback
only — live data still arrives through the runtime fetch.
