# Generated goals data

Do not edit this file by hand. It is regenerated by the upload pipeline and any
manual change is lost on the next run.

| File                  | Script                 | Committed |
| --------------------- | ---------------------- | --------- |
| `goals.manifest.json` | `npm run goals:upload` | Yes       |

It holds public delivery information only: goal ids, competition and scorer
metadata, Cloudinary public ids and public URLs. It never contains a credential,
a signature or a local absolute path.
